## How posts work

Every post is a Markdown file in the blog's data folder on the server. Astro renders it on request, so anything saved in the editor is live straight away, and the pages ship with almost no JavaScript.

- **Bold**, *italic*, and `inline code` all work.
- So do [links](https://github.com/Verslabs/Ruby), lists, and quotes.

> The newest post also shows up as a preview on the main page.
